The hero is a three-step picker — subject, then language, then time — not a decorative illustration. Rationale (approved plan): * Goal before friction. Asking what someone wants before asking them to work is the ordering that both the onboarding research and this site's own sign-up flow use. Subject leads. * Language is a real differentiator. Regional-language instruction is the clearest growth lever in Indian tutoring, and neither UrbanPro nor Superprof asks it up front. "Any language" is pre-selected so it costs the indifferent majority one tap. * Everything tapped here travels into /register/ as query params, so the first three sign-up questions are already answered before an account exists. Both option lists come from the database via apps/web/taxonomy.py, rendered server-side by Django (not x-for), so the taxonomy is in the initial HTML for crawlers and a Super Admin's additions appear without a deploy. Honesty constraints held throughout: - No invented volume metrics; /public/stats/ figures render only when > 0. - No "message teachers directly" claim — there is no student-to-teacher messaging in this product. - Marigold appears exactly twice: the step-3 CTA and the closing CTA. {% endcomment %} {% block body %}
